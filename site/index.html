The ledger

A receipt, not a preview

One mono line fused to the top of the composer: one chip per memory, each with what it costs, and a running total against the cap. It updates as you pause, so you watch the retrieval happen before you commit to it.

It is not a summary of the context. It is the context. Every path that injects anything goes through one function, and the interface renders that function's exact output — if the line and what gets sent could ever disagree, that is a critical bug, not a rounding error.

The brain

A folder of markdown notes

One file per memory, the file stem as its id, [[wikilinks]] as authored edges. No database you can't read, no format you can't grep. Point it at an Obsidian vault if you like.

Nothing is injected unless a message mentions /brain. That turn's question then seeds a walk over the memory graph — wikilinks, embedding similarity, shared use — for the notes that answer you. Every other message reaches the model bare.

Embeddings run locally by default, on a bundled model that loads when it is needed and is dropped the moment it isn't. Nothing about your notes leaves the machine unless you point the embedder at an endpoint yourself — and the app says so, in the header, the whole time you do.

/memory  saves a note
/update-memory  rewrites the one it belongs to
/delete-memory  moves it to .trash
/link-memory  draws an edge
/unlink-memory  takes it back out

One tool per mention — the choice between them is yours, not the model's.

The models

Open weights, as a rule

Not a default you can talk it out of. Any OpenAI-compatible endpoint and a local Ollama; never a closed-weight provider.

The providers view already knows the endpoint and the model list for OpenRouter, Groq, Cerebras, DeepSeek, Together, Mistral, OpenCode Zen and Ollama — so a key is the whole of what it asks for. Paste one and a shape only one provider issues names its own. Free models are listed first, everywhere.

Keys live in odyn.toml, or stay out of it entirely: api_key_env names an environment variable that is read only when that provider is actually used.

Spotlight

⌥Space, anywhere

A borderless panel that answers without taking focus from whatever you were doing — the app in front of you keeps the caret. Ask, read, dismiss with Esc. Or promote the exchange into a full conversation and keep going.

Odyn otherwise lives in the menu bar. Closing the dashboard only hides it, because the hotkey has to keep answering.
